# 🌉 EchoDub Bridge (هاب و سرور ایران)

سرور واسط داخل ایران برای:
1. **استریم پرسرعت ویدیویی بدون فیلترشکن** برای کاربران سایت `downloadly.ir`.
2. **میزبانی وب‌اپلیکیشن استودیوی دوبله** با سرعت داخلی (پینگ زیر ۲۰ میلی‌ثانیه).
3. **درج خودکار پلیر ویدیویی و لینک‌های دانلود در پست‌های وردپرس Downloadly.ir**.
4. **ارسال جاب‌های دوبله به سرور آمریکا و مدیریت وضعیت**.

---

## 🚀 دیپلوی روی Coolify (سرور ایران)

1. در پنل Coolify سرور ایران، ریپازیتوری `ashoorijahanban1-dev/echo-dub-bridge` را ادد کنید.
2. متغیرهای محیطی را تنظیم کنید:
   - `US_WORKER_API_URL`: آدرس سرور آمریکا (مثلاً `http://IP_AMERICA:8000`).
   - `WORDPRESS_SITE_URL`: `https://downloadly.ir`.
   - `WORDPRESS_REST_USER` و `WORDPRESS_APP_PASSWORD`: نام کاربری و App Password وردپرس.
3. دکمه **Deploy** را بزنید! پورت `8080` باز می‌شود و فرانت‌اند استودیو و استریم پروکسی فعال می‌گردد.
